# Changelog

## Unreleased

- Graphics: "Close them all" (and `kk-gpu free`) closes every app using the NVIDIA card so a mode switch or switching the card off has nothing holding on to it; the desktop and the shell are never touched.
- Crash guard: a closed overlay or emoji picker keeps its empty window for a third of a second before it is destroyed, so Qt never tears down a surface that still has a focused text field (the last thing in the shell logs before it died).
- Right-click to edit: a desktop widget's menu (bigger, smaller, put back, let the shell place it, hide); the bar's menu on its empty space or the logo (style, top or bottom, hide, choose modules). The logo is now a kitty.
- Our own apps (software centre, task manager, running apps, clipboard, phone) sit in the bar's tray, ahead of other apps' icons.
- Settings: the refresh-rate choices are the ones each screen really reports; removed the Bluetooth-reconnect, clipboard-history and quit-apps-when-their-last-window-closes switches (always on / fixed: apps close a few seconds after their last window unless allowed).
- The wallpaper picker also reads ~/Videos/wallpapers and ~/Videos/live, and shows a frame of every live wallpaper.
- Fastfetch is a traditional layout with a hand-drawn ascii cat; no wallpaper figure, no current-wallpaper line.
- Storage: "App caches" no longer deletes the gpu shader, font and qml caches the running shell has open (that crashed the shell on Clean). Clean-ups that need your password step the overlay aside so the prompt is visible, and show a spinner while they work.
- Lighter shell: live wallpapers decode at 24 fps with small buffers and freeze while a window is fullscreen; the visualiser tops out at 96 bars / 30 fps; system stats sample every 5 s on battery; the wallpaper workspace is capped at 768 MB.
- Every desktop widget has a corner dot: drag it to resize (right-click for exact steps, hide, put back). The notepad drags by its top strip so you can click and select text in it; edits made elsewhere show up in it. The music bars have no settings page any more: right-click them (full width or boxed) for style, placement, edge, colour, size, number of bars, gaps, see-through, smoothness, rounding, sparks and behind-the-subject.
- Emoji picker: stays open. Every click (or Enter) pastes that emoji into the window you were in; Esc or a click elsewhere closes it.
- Switching wallpaper no longer blanks the screen for a moment: a live wallpaper is stopped only after the still picture is back on screen.
- Projection: "External only" no longer flips back to extend a second later (the shell mistook the screens its own reload re-added for a new cable); unplugging the external screen turns the laptop's back on; overlays, toasts and the volume pop-up always land on a screen that is really on, so the menu opens in external-only mode too.
- Visualiser: if cava is running but hears nothing while music plays (a new wallpaper or its video took the audio device), it restarts; a wallpaper change always restarts the feed.
- Storage clean-ups say what they freed (or that there was nothing to clean), the recycle bin really empties, the wallpaper workspace cleans everything but the current wallpaper, old packages fall back to `pacman -Sc` without paccache, a second click during a running clean-up is no longer silently dropped.
- Qt 6.12 "insufficiently annotated" errors (Apps, Wall and others): every function now has typed parameters.
- Visualiser: any style full width (bottom, top, middle) or in a box; height, bars, gap, rounding, see-through, smoothness, colour (wallpaper, accent, album, rainbow).
- Music fun: a bouncing clock, sparks on the beat, an edge glow in the album's colour.
- The visualiser restarts by itself when its audio input changes (it used to freeze after a wallpaper or output change).
- Keeping things: clipboard history capped and emptied at each login, the recycle bin empties itself, optional ages for screenshots and recordings; a tidy every three hours.
- Example live wallpapers made locally with ffmpeg (kk-livewalls); kk-showcase records readme screenshots and clips.
- Cheatsheet lists the keys inside the shell's own screens; readme rewritten.
- Control center: one tap switches Wi-Fi and Bluetooth (the arrow opens the list); a battery page with health, watts, cycles, energy and the last 24 hours.
- Bluetooth: paired devices are trusted and saved, reconnect after Bluetooth is switched off and on, retry a failed connect, and have their own controls (auto-connect, block, send file, pair again, forget).
- Phone panel over KDE Connect (new `phone` extra): battery, ring, files, clipboard, browse storage, texts.
- Running apps panel and bar pill: every app, including tray and background apps, with focus, menu, quit and force quit; optional no-background-apps mode. Tray icons open their menu on one tap.
- Task manager (Ctrl + Shift + Esc): processes, memory, storage clean-up, recycle bin, drives with mount/eject/format.
- Software centre: repos, AUR and Flathub in one search; installed, updates, developer bundles and a basics check.
- Graphics: NVIDIA-only mode, switch the NVIDIA card off, heavy apps start on it, and a hint when one starts on the integrated card.
- Workspaces: no gaps after closing one, no empty placeholders, sign-in pages bring you to the browser, overview steps with Super + Tab / arrows and scrolls while dragging, windows can be dropped on other screens.
- Projection: every mode can follow every other (mirror and single-screen modes reset cleanly), rescan reports what it found, no extend-left card; screenshots and recordings take the screen under the pointer or a chosen one.
- Fixes: the 12-hour clock on the desktop, lock screen and vertical bar; weather unit and network toggles apply at once; the clock finds a calm, open spot when it can't tuck behind the subject; the emoji picker pastes into the app you were in and opens in its corner; Super + E always opens a new window; the Up arrow leaves the cursor at the end of the line.
- Installer: records the system before the first install and every system file it changes; `--rollback`; `--update` fetches only the newest dotfiles. `uninstall.sh --all` restores the previous system completely.
- Wallpaper pack is now opt-in; the storage page trims unused wallpaper caches.
- Nautilus themed from the wallpaper, with format/disk usage/send-to-phone/admin scripts; security toolkit extra and `kk-cybersec`.
- Added explicit installer update, dry-run, snapshot, and restore modes.
- Added manifest-aware uninstall with a dry-run preview.
- Added package manifest validation and CI workflows.
- Added direct emoji insertion.
- Added a compact traditional emoji picker with categories and recent emojis.
- Added a dedicated projection menu with automatic HDMI/DP extension.
- Added a graphical package search and install/remove manager.
- Added random wallpaper and monitor hot-plug handling.
