# Changelog

## Unreleased

- Notepad takes typing again: a click in it lifts the desktop layer and hands it the keyboard (a bottom-layer surface was never given keyboard focus); clicking anywhere else or Esc gives it back.
- Super + Q on an app with other windows open (Nautilus, browsers) closes only that window instead of killing the process, which closed every one of its windows.
- Right-click a desktop widget: its own options in plain words (clock face, 12/24-hour, colour; player look; weather units, rain and snow, city; timer lengths) and Hide. Moving and sizing are by hand. The Bigger / Smaller / Put back list is gone.
- Settings: each widget has its own group. Removed the wallpaper switch speed, the typed lists (apps allowed in the background, heavy NVIDIA apps), the lyrics folder path, the doctor and settings-file rows; the keyboard layout is a choice of names.
- Wallpaper picker opens at once again: listing no longer waits for ffmpeg to grab a frame of every live wallpaper. Missing thumbnails (pictures too, at 480 px) are made afterwards in the background and the picker fills them in.
- The prepared-wallpaper cache is back to 1.5 GB (512 MB kept throwing out prepared wallpapers and re-making them, so switches started from scratch).
- Switching waits at most 0.9 s for a new picture's ink (was 4 s), and the ink takes 1.6 s (was 4.2 s). Settings → Wallpaper → Switch speed: quick, normal or slow.
- Right-click the music bars: a small popup with shape, where (across the screen or in a box), which edge, how many bars, space between them, how rounded (now a slider, not on/off) and how tall. Colour, how solid, movement and behind-the-subject are in Settings → Desktop. The box resizes by dragging its corner.
- Fixes after the last few updates: login starts the shell even when `kk-shell` isn't installed yet (it had been committed without its executable bit, and Hyprland ran it from ~/.local/bin, which a plain `git pull` never fills, so the whole shell and every shell shortcut stayed dead). Super + E falls back the same way.
- Nautilus is the file manager again (installed with the apps; Super + E, folders and the dock use it). Thunar stays as a fallback.
- Apps are no longer killed when their last window closes. That is opt-in again, off by default, with the switch back in the running-apps panel (tray apps like Discord, Steam or Spotify kept dying).
- The app drawer (Super + Space) lists Kajukatli's own apps too: Task Manager, Software, Displays, Projection, Settings, Control Center, Running Apps, Phone, Wallpapers, Clipboard, Notes, Emoji, Screenshot & Record, Shortcuts.
- The visualiser's easing setting no longer redefines Qt's built-in `smooth` property.
- Graphics: "Close them all" (and `kk-gpu free`) closes every app using the NVIDIA card so a mode switch or switching the card off has nothing holding on to it; the desktop and the shell are never touched.
- Crash guard: a closed overlay or emoji picker keeps its empty window for a third of a second before it is destroyed, so Qt never tears down a surface that still has a focused text field (the last thing in the shell logs before it died).
- Right-click to edit: a desktop widget's menu (bigger, smaller, put back, let the shell place it, hide); the bar's menu on its empty space or the logo (style, top or bottom, hide, choose modules). The logo is now a kitty.
- Our own apps (software centre, task manager, running apps, clipboard, phone) sit in the bar's tray, ahead of other apps' icons.
- Settings: the refresh-rate choices are the ones each screen really reports; removed the Bluetooth-reconnect, clipboard-history and quit-apps-when-their-last-window-closes switches (always on / fixed: apps close a few seconds after their last window unless allowed).
- The wallpaper picker also reads ~/Videos/wallpapers and ~/Videos/live, and shows a frame of every live wallpaper.
- Fastfetch is a traditional layout with a hand-drawn ascii cat; no wallpaper figure, no current-wallpaper line.
- Storage: "App caches" no longer deletes the gpu shader, font and qml caches the running shell has open (that crashed the shell on Clean). Clean-ups that need your password step the overlay aside so the prompt is visible, and show a spinner while they work.
- Lighter shell: live wallpapers decode at 24 fps with small buffers and freeze while a window is fullscreen; the visualiser tops out at 96 bars / 30 fps; system stats sample every 5 s on battery; the wallpaper workspace is capped at 768 MB.
- Super + E opens whichever file manager is installed (thunar first, then nautilus, nemo, pcmanfm, dolphin) through `kk-files`, and offers to install thunar if there is none. The shell now runs under `kk-shell`, which starts it again within a second if it ever crashes, so shell shortcuts do not stay dead.
- Battery options: every saving the battery saver makes has its own switch (settings → power: music bars, ink animation, pointer parallax, window animations, beat glow and clock bounce, slower apps list), and the idle times on battery are yours to choose (dim, screen off, sleep). `kk-idle` writes hypridle's config from them.
- Fixed: the shell locking itself and "the lockscreen app died". kk-shell restarted the shell with the session's environment, which still said "start in the lock screen", so every restart (for instance after a crash on a wallpaper switch) locked the screen again and played the lock sound; the lock is now taken back only if the old shell died while the screen was locked. The forced garbage collection at the end of every wallpaper switch is gone (a hitch, and a crash risk).
- Battery: unplugged (battery saver on) there is no audio analysis, no ink shader (a short fade), no pointer parallax, no window animations, no beat glow or clock bounce; `ps` runs every 12 s instead of 3; the screen dims after 1 minute, sleeps after 2, the machine after 7.
- Back to yesterday's behaviour: widgets use yesterday's drag code (grab anywhere; ctrl + scroll or the right-click menu to resize; no ctrl + drag, which moved widgets), plus right-click and the notepad's top strip; the clock picks its spot from the subject's outline as before (a later "calm spot" detour moved it away from the character when the cut-out was not ready); the wallpaper decodes the cut-out, depth and ink maps as before; the player's play, next and previous always try, whatever the player says it can do.
- Widget popups (the music bars especially) no longer close after a tenth of a second: they were treated as typing, which lifted the desktop window and armed a focus grab that cleared at once. The music bars sit above the clock (it was taking their clicks). Widgets drag from anywhere again, as before (only the notepad uses its top strip), which also gives the player's buttons their clicks back. Cleaning "wallpaper workspace" only removes what was unused for 30 days again: it had been deleting every other wallpaper's cut-out, which is why the clock stopped going behind the character until each picture was worked out again (that needs the charger, or settings → wallpaper → work on battery too). Music bars default to 8% of the screen. While a wallpaper switches, the bars and the behind-the-subject texture hold still. Blur stays on when unplugged (terminal glass). Nautilus keeps its background service running from login so Super + E opens instantly.
- Back as it was: the ink spread runs at its full length again (4.2 s, and the wallpaper waits up to 4 s for its ink map), and the clock decides for itself again, so it goes behind the wallpaper's subject (looks, "put back" and resetting the layout had been pinning it to a fixed spot). Music bars are lower by default (15% of the screen, smaller boxes, fewer wave points). Widgets resize with ctrl + drag (a dot appears under ctrl and in arrange mode), so the player's buttons are no longer covered. Settings uses the kitty logo. Applying a look writes settings once instead of a dozen times (switching stuttered).
- Super + Q goes through `kk-close`: it still kills the focused window outright, but never takes the shell with it. The settings window is a window of the shell process itself, so killing it killed the shell; a terminal that is running the shell would do the same. Those are closed politely (or, for the terminal, left alone with a note).
- Fixed: the cheatsheet showed no key combinations (a function declared to return a string returned a list, which Qt 6.12 turns into nothing); hyprland no longer paints "your config has errors" over the screen for the 4-finger gestures on versions that want a different action form; closing the settings window could make the shell terminate itself (it counted the settings window as an app that had lost its last window): the shell is never reaped. Files are Nautilus only, in the shell's colours (sidebar, path bar, selection) with the right-click scripts moved over (terminal here, send to phone, storage, edit as administrator); Thunar is gone.
- The notepad is a fixed-size card that scrolls (it no longer grows with its text). Shell windows (overlays, toasts, emoji picker) keep the screen they opened on instead of hopping to another output when the focus moves (re-homing a live layer-shell window is a crash risk). Album-art colours refresh on every track.
- Every desktop widget has a corner dot: drag it to resize (right-click for exact steps, hide, put back). The notepad drags by its top strip so you can click and select text in it; edits made elsewhere show up in it. The music bars have no settings page any more: right-click them (full width or boxed) for style, placement, edge, colour, size, number of bars, gaps, see-through, smoothness, rounding, sparks and behind-the-subject.
- Emoji picker: stays open. Every click (or Enter) pastes that emoji into the window you were in; Esc or a click elsewhere closes it.
- Switching wallpaper no longer blanks the screen for a moment: a live wallpaper is stopped only after the still picture is back on screen.
- Projection: "External only" no longer flips back to extend a second later (the shell mistook the screens its own reload re-added for a new cable); unplugging the external screen turns the laptop's back on; overlays, toasts and the volume pop-up always land on a screen that is really on, so the menu opens in external-only mode too.
- Visualiser: if cava is running but hears nothing while music plays (a new wallpaper or its video took the audio device), it restarts; a wallpaper change always restarts the feed.
- Storage clean-ups say what they freed (or that there was nothing to clean), the recycle bin really empties, the wallpaper workspace cleans everything but the current wallpaper, old packages fall back to `pacman -Sc` without paccache, a second click during a running clean-up is no longer silently dropped.
- Qt 6.12 "insufficiently annotated" errors (Apps, Wall and others): every function now has typed parameters.
- Visualiser: any style full width (bottom, top, middle) or in a box; height, bars, gap, rounding, see-through, smoothness, colour (wallpaper, accent, album, rainbow).
- Music fun: a bouncing clock, sparks on the beat, an edge glow in the album's colour.
- The visualiser restarts by itself when its audio input changes (it used to freeze after a wallpaper or output change).
- Keeping things: clipboard history capped and emptied at each login, the recycle bin empties itself, optional ages for screenshots and recordings; a tidy every three hours.
- Example live wallpapers made locally with ffmpeg (kk-livewalls); kk-showcase records readme screenshots and clips.
- Cheatsheet lists the keys inside the shell's own screens; readme rewritten.
- Control center: one tap switches Wi-Fi and Bluetooth (the arrow opens the list); a battery page with health, watts, cycles, energy and the last 24 hours.
- Bluetooth: paired devices are trusted and saved, reconnect after Bluetooth is switched off and on, retry a failed connect, and have their own controls (auto-connect, block, send file, pair again, forget).
- Phone panel over KDE Connect (new `phone` extra): battery, ring, files, clipboard, browse storage, texts.
- Running apps panel and bar pill: every app, including tray and background apps, with focus, menu, quit and force quit; optional no-background-apps mode. Tray icons open their menu on one tap.
- Task manager (Ctrl + Shift + Esc): processes, memory, storage clean-up, recycle bin, drives with mount/eject/format.
- Software centre: repos, AUR and Flathub in one search; installed, updates, developer bundles and a basics check.
- Graphics: NVIDIA-only mode, switch the NVIDIA card off, heavy apps start on it, and a hint when one starts on the integrated card.
- Workspaces: no gaps after closing one, no empty placeholders, sign-in pages bring you to the browser, overview steps with Super + Tab / arrows and scrolls while dragging, windows can be dropped on other screens.
- Projection: every mode can follow every other (mirror and single-screen modes reset cleanly), rescan reports what it found, no extend-left card; screenshots and recordings take the screen under the pointer or a chosen one.
- Fixes: the 12-hour clock on the desktop, lock screen and vertical bar; weather unit and network toggles apply at once; the clock finds a calm, open spot when it can't tuck behind the subject; the emoji picker pastes into the app you were in and opens in its corner; Super + E always opens a new window; the Up arrow leaves the cursor at the end of the line.
- Installer: records the system before the first install and every system file it changes; `--rollback`; `--update` fetches only the newest dotfiles. `uninstall.sh --all` restores the previous system completely.
- Wallpaper pack is now opt-in; the storage page trims unused wallpaper caches.
- Nautilus themed from the wallpaper, with format/disk usage/send-to-phone/admin scripts; security toolkit extra and `kk-cybersec`.
- Added explicit installer update, dry-run, snapshot, and restore modes.
- Added manifest-aware uninstall with a dry-run preview.
- Added package manifest validation and CI workflows.
- Added direct emoji insertion.
- Added a compact traditional emoji picker with categories and recent emojis.
- Added a dedicated projection menu with automatic HDMI/DP extension.
- Added a graphical package search and install/remove manager.
- Added random wallpaper and monitor hot-plug handling.
